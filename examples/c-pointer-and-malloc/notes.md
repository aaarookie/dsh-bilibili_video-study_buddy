## 一、指针是"存地址的变量" [01:00]

![指针概念](frames/BV1HE421j7Lt_P5_60s.jpg)

**画面原话**（字幕）："这个空间里面存放的是整数"

**画面上的代码**：

```c
int a = 10;
```

**老师画的图**：一个方框代表 `a` 这块内存，框里写 10，旁边标注"整数 10"。

**讲解**：

`int a = 10;` 做两件事——向系统要一块能放下 `int` 的内存（通常 4 字节），然后把 10 存进去。
这块内存在哪、叫什么，你在代码里看不到，但 CPU 访问它必须靠**地址**。

所以：

- `a` 是**这块内存的名字**，编译后其实变成了地址；
- `&a` 是**取出这个地址**；
- 指针就是**专门用来存地址的变量**。

```c
int a = 10;
int *p = &a;   // p 里存的是 a 的地址，不是 10
printf("%d\n", *p);   // 10
```

> 💡 **一句话记忆**：`*` 在**声明**里表示"这是个指针"，在**表达式**里表示"顺着地址去找"。

**易错点**：

- `int *p` 里的 `*` 不是解引用，是类型的一部分；
- `p` 的值是地址，`*p` 的值才是 10；
- 野指针（没初始化的 `int *p;`）不能解引用。

## 二、数组名就是首元素地址 [06:30]

![数组与指针](frames/BV1HE421j7Lt_P5_390s.jpg)

**画面原话**（字幕）："然后 A 加 3"

**画面上的代码**：

```c
int A[5] = {7, 3, 5, 2, 9};
```

**老师画的图**：把数组画成 5 个连续的格子，下标 0~4，值依次是 7、3、5、2、9；
`A` 被圈起来，箭头指向**第 0 格**；下面标注 `A+1`、`A+2`、`A+3` 各指向后面一格。

**画面下方两组等价写法**：

```c
A[0];   *A;        // 等价
A[2];   *(A + 2);  // 等价
```

**讲解**：

数组名 `A` 在大多数表达式里会**退化成首元素地址**，也就是 `&A[0]`。

于是下标运算 `A[i]` 本质上是 `*(A + i)` 的语法糖：

| 写法 | 含义 | 取到的值 |
|---|---|---|
| `A[0]` / `*A` | 首元素 | 7 |
| `A[2]` / `*(A+2)` | 第 3 个元素 | 5 |
| `A + 3` | 指向第 4 个元素的**地址** | 地址值，不是 2 |

> ⚠️ **最关键的区分**：`A+3` 是**地址**，`*(A+3)` 才是**值**（2）。
> 初学最常见的错就是拿 `A+3` 去当值用。

**为什么 `A+1` 会跳到下一个元素，而不是下一个字节？**

因为指针有类型。`int*` 加 1，实际地址加的是 `sizeof(int)`（4 字节）。
这也是后面 `malloc` 里 `sizeof(int) * 10` 的由来。

## 三、栈上的指针 vs 堆上的内存 [12:00]

![栈与堆](frames/BV1HE421j7Lt_P5_720s.jpg)

**画面原话**（字幕）："那动态内存分配"

**画面上的代码（左：指向栈变量）**：

```c
int a = 10;
int *p;
p = &a;
```

**老师画的图（左）**：`a` 的方框里是 10，下面标"地址 A"；`p` 的方框里存"地址 A"，标注在"栈"上。

**画面上的代码（右：指向堆内存）**：

```c
int *p;
p = (int *)malloc(sizeof(int));
*p = 10;
```

**老师画的图（右）**：`p` 在栈上，里面存一个地址，箭头指向**堆**里另一个方框（标"地址 B"），框里是 10。

**讲解**：

两种写法都能让 `*p == 10`，但内存归属完全不同：

| | 左边（`p = &a`） | 右边（`malloc`） |
|---|---|---|
| `p` 本身在哪 | 栈 | 栈 |
| `p` 指向的 10 在哪 | 栈（局部变量 `a`） | **堆** |
| 谁负责释放 | 函数返回自动回收 | **必须手动 `free(p)`** |
| 生命周期 | 跟着作用域 | 直到你 free |

**为什么需要 malloc？**

栈空间有限（通常几 MB），而且函数一返回就没了。
要在运行时决定大小、或者让数据活得更久，就得去堆上要内存。

**易错点**：

- `malloc` 返回 `void*`，C 里可以不转，C++ 里必须转；
- 分配后不检查 `p == NULL`（内存不足时返回 NULL）；
- **忘了 `free`** → 内存泄漏；
- `free` 之后继续用 → 悬空指针。

## 四、用 malloc 造一个数组 [18:00]

![malloc 造数组](frames/BV1HE421j7Lt_P5_1080s.jpg)

**画面原话**（字幕）："这是动态分配"

**画面上的代码**：

```c
int A[10] = {1, 5, 7};                              // 静态数组
int *A = (int *)malloc(sizeof(int) * 10);           // ⚠️识别存疑：与上一行重名
```

**老师画的图**：一排 10 个格子，`A` 指向第一格。

**讲解**：

这里在对比"静态数组"和"动态申请一段连续空间"两种写法，
但**两行写在一起会重定义 `A`**，实际编译不过——老师是在并列展示两种写法，不是叫你连写。

正确的两种写法：

```c
// 写法一：静态数组，大小编译期确定
int A[10] = {1, 5, 7};        // 后 7 个元素自动补 0

// 写法二：动态数组，大小运行期确定
int n = 10;
int *A = (int *)malloc(sizeof(int) * n);
if (A == NULL) { /* 分配失败，必须处理 */ }
A[0] = 1; A[1] = 5; A[2] = 7;
// ... 用完
free(A);
A = NULL;                      // 防止悬空指针
```

**为什么是 `sizeof(int) * 10` 而不是 `10`？**

`malloc` 的参数单位是**字节**，不是元素个数。
一个 `int` 要 4 字节，10 个就要 40 字节。写 `malloc(10)` 只给你 10 字节，够存 2 个半 int，
后面写 `A[5]` 就越界了——这种 bug 往往不报错，只在你考试或上线时爆炸。

> ⚠️ **识别存疑**：画面手写是 `malloc(sizeof(int)*10)`，中间那个 `*` 与 `+` 形近，请回看 [18:00](https://www.bilibili.com/video/BV1HE421j7Lt?p=5&t=1080) 确认。

## 完整代码串联

把这一节的四段拼成一个能跑的程序：

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    // 1. 指针的基本含义 [01:00]
    int a = 10;
    int *p = &a;
    printf("a=%d, *p=%d, &a=%p, p=%p\n", a, *p, (void*)&a, (void*)p);

    // 2. 数组名与指针 [06:30]
    int A[5] = {7, 3, 5, 2, 9};
    printf("A[2]=%d, *(A+2)=%d\n", A[2], *(A + 2));

    // 3. 栈 vs 堆 [12:00]
    int *q = (int *)malloc(sizeof(int));
    if (q == NULL) return 1;
    *q = 10;
    printf("*q=%d\n", *q);
    free(q);
    q = NULL;

    // 4. 动态数组 [18:00]
    int n = 10;
    int *arr = (int *)malloc(sizeof(int) * n);
    if (arr == NULL) return 1;
    for (int i = 0; i < n; i++) arr[i] = i * i;
    printf("arr[9]=%d\n", arr[9]);
    free(arr);
    arr = NULL;

    return 0;
}
```

## 自测（先别翻上面的答案）

1. `int *p; *p = 10;` 有什么问题？
2. `A[3]` 和 `*(A+3)` 和 `A+3`，哪个是值、哪个是地址？
3. `malloc(10)` 和 `malloc(sizeof(int)*10)` 差在哪？后者多要了多少字节？
4. 下面这段有没有内存问题？
   ```c
   int *f() { int x = 5; return &x; }
   ```
5. 为什么要 `free(A); A = NULL;` 两步，只 `free` 不行吗？

<details>
<summary>参考答案</summary>

1. `p` 未初始化，是野指针，解引用是未定义行为（可能崩溃）。
2. `A[3]` 和 `*(A+3)` 是**值**；`A+3` 是**地址**。
3. 前者 10 字节，后者 40 字节（`sizeof(int)=4`），差 30 字节。
4. 有。返回了局部变量的地址，函数返回后栈帧失效 → 悬空指针。
5. 只 `free` 后指针仍指向已释放内存，再次使用是悬空指针；置 `NULL` 让误用变成可检测的空指针崩溃。

</details>
