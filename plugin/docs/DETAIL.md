# B 站网课伴学（dsh-bilibili_video-study_buddy）

给 DSH 模型四个工具，把「看一节课」拆成可组合的原子动作。核心判断是：
**模型不该“看整段视频”，而该在正确的时间点看正确的画面。**

## 四个工具

| 工具 | 做什么 | 什么时候用 |
|---|---|---|
| `study_frame` | 按时间点抽帧，返回图片路径 + `?t=` 回看链接 | 已知道大概在第几分钟 |
| `study_scan` | 一段区间抽 N 帧、缩成小格子拼一张图 | 只知道“大概在这 5 分钟里” |
| `study_subs` | 取 AI 字幕 + **串台检测** | 想拿文字稿，且先确认字幕可信 |
| `study_asr` | 局部转写，默认带前 60s 铺垫 + 后 30s 延续 | 没有字幕，或要听老师原话 |

## 为什么这么设计

### 1. 拼图只用来定位，不用来读代码

一格 400px 宽能看清“这屏是幻灯片还是 IDE”，读不清代码。
6 格拼一张约 600 token，而 6 张 1080P 单帧约 5,850 token——**省 89%**。
所以流程是：`scan` 定位 → `frame` 精读。

### 2. 抽帧默认裁剪

录屏课的画面上有大量无效像素：浏览器工具栏、播放器 UI、右下角人脸小窗、底部字幕条。
裁掉这些，同样的 token 预算下有效信息密度高得多：

| 方案 | 尺寸 | 估算 token |
|---|---|---|
| 整帧 | 1654×1080 | ~1768 |
| **裁剪** | **1234×800** | **~975（省 45%）** |
| 裁 + 放大 2x | 2468×1760 | ~4290（没必要） |

放大不会产生新信息，只是把已有像素摊开。

### 3. 字幕必须校验

B 站的 AI 字幕会**串台**——实测一门 GPT 课拿到了“核能/浓缩铀”和英文歌词两种完全无关的文稿。
所以 `study_subs` 用三个独立信号判定：

- **覆盖度**：字幕最后一条时间 / 视频时长（正常 > 0.8）
- **标题术语命中**：标题里的英文词是否出现在字幕里
- **语速合理性**：平均每条字幕的时长

判 FAIL 时默认拒绝输出正文。

### 4. ASR 不裸切

只给 90 秒，能讲清“这段在做什么”，但讲不清“这是新概念还是回顾”。
所以默认往前多取 60 秒、往后多取 30 秒。

## 安装

```bash
dsh plugin --profile web add dsh-bilibili_video-study_buddy
```

或在 DSH 的 **设置 → 插件 → 添加插件** 里填包名。

装完重启一次 DSH。

## 依赖

| 依赖 | 必需？ | 说明 |
|---|---|---|
| Node ≥ 20 | ✅ | 插件本体 |
| `ffmpeg` | ✅ 抽帧/扫描需要 | 放进 PATH，或在配置里指定路径 |
| B 站登录态 | 可选 | 有登录能拿 1080P 和 AI 字幕 |
| `faster-whisper` | 仅 `study_asr` | Python 3.10–3.14 + 模型 |

登录态读取顺序：

1. 配置里的 `credentialFile`
2. 环境变量 `BILI_WATCH_CRED`
3. `$DSH_HOME/bili-watch/credential.json`
4. `~/.dsh/bili-watch/credential.json`
5. 环境变量 `SESSDATA`

和 `dsh-bili-watch` 共用同一份凭证，装过它就不用再登录。

## 配置

```yaml
- id: dsh-bilibili_video-study_buddy
  config:
    credentialFile: ""   # 自定义凭证路径
    ffmpeg: ""           # ffmpeg 绝对路径
    python: ""           # faster-whisper 的解释器
```

## 限制（都是实测出来的）

- **时间点属于某个分 P**，不是整条视频。多 P 课程必须给对 `page`，否则会抽到空文件。
- **匿名最高 640×480**。要 1080P 必须登录。
- **ASR 会系统性听错代码术语**：`free(p)` → “4AP”、`栈上` → “站上”。代码一律以画面为准。
- **拼图看不清代码**，只够定位。
- **只读**：不点赞、不评论、不投币；凭证只存在本机。
