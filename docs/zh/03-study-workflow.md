# 03 · 网课学习实操方案

> 前提：已按 [04](04-install-and-pitfalls.md) 装好 `dsh-bili-watch` 与 `dsh-bili-study`。
> 本文所有提示词都可直接复制到 DSH 对话框，`{}` 是你要替换的部分。

---

## 零、先摆正预期

**AI 不是替你看课，是替你做三件事：**

| 它擅长 | 它不擅长 |
|---|---|
| 把 60 分钟的口播压成 10 条知识点 | 判断哪条对你**重要**（它不知道你的基础） |
| 把散落的时间点整理成结构 | 替你建立直觉（数学推导、算法手感） |
| 随时回答"刚才那个词什么意思" | 发现老师讲**错了**（它倾向于附和） |
| 出题、批改、追踪错题 | 替代你动手做题 |

所以正确姿势是：**你负责看和想，它负责记录、检索、追问、出题。** 别把课丢给它然后去干别的。

---

## 一、五步闭环

```
① 定位  ── 搜课/锁课，确认这节值不值得看
② 取文  ── 字幕或转写拿到手（带时间码！）
③ 切段  ── 按 10~15 分钟切，每段一个知识点块
④ 落笔  ── 生成带时间码的笔记，存进学习台
⑤ 自测  ── 出题 → 答错 → 回跳时间码重看 → 记错题
```

第 ③ 步是全流程的关键。**不要一次让 AI 总结整节课**——它会把细节抹平成正确的废话。
按段处理，每段保留「原话要点 + 时间码」，最后再合并。

## 二、场景 A：有字幕的课程（最常见，也最省事）

### A1. 拿字幕

在 DSH 里直接说：

```
用 bili_watch 把 {BV号或链接} 的字幕导出来，md 格式，带时间码，存到当前目录。
```

模型会调 `bili_watch` 的 `sub` 命令，产出形如：

```markdown
[00:00] 今天我们来讲进程调度
[00:08] 先回顾一下进程的状态
[01:23] 调度器要解决的核心问题是……
```

> 💡 `sub` 需要 B 站登录态。没登录时会返回"无字幕轨"——那就走场景 B。
> 💡 多 P 视频记得说「第 3 P」，命令里是 `--p 3`。

### A2. 分段精讲（核心提示词）

```
下面是一门课的某一节字幕，带 [mm:ss] 时间码。
请按内容自然分段（每段 8~15 分钟，不要按固定字数切），
每段输出：

### 段落 N｜{一句话概括}｜[{起始时间}-{结束时间}]
- **讲什么**：2~3 句，用人话，不要照抄原文
- **关键结论**：1~3 条，能被单独引用的那种
- **前置概念**：这段假设你已经知道什么（列出来，别解释）
- **没讲清的**：这段里老师一带而过、但可能是坑的地方
- **回看锚点**：如果只重看 30 秒，看哪一刻，为什么

最后给一张全节的知识结构（缩进列表即可，不要画 mermaid）。

字幕：
{把 srt/md 内容贴进来，或让模型 read 落盘的文件}
```

**为什么这样设计**：
- 「前置概念」暴露你的知识缺口——这是自学最容易卡住的地方；
- 「没讲清的」是留给后面追问的钩子；
- 「回看锚点」比"完整重看"高效 10 倍。

### A3. 追问（真正的学习发生在这里）

不要问"这段讲了什么"（你已经有了）。要问：

```
针对第 12:30 那个「时间片轮转」的例子，我有个疑问：
如果所有进程优先级相同，轮转和时间片大小有什么关系？
老师好像没展开。请用一个小例子说明，并指出我理解里可能的误区。
```

```
这段里「临界区」和「互斥量」我分不清。
请用"两个人抢一支笔"的比喻讲一遍，然后告诉我：
在什么场景下这两个词**不能**互换使用？
```

> 心法：**追问要带时间码和具体名词**。模糊的问题得到模糊的答案。

## 三、场景 B：没有字幕的课程

B 站大量老课程、录屏课没有字幕。两条路：

### B1. 本地 ASR（免费，吃 CPU/GPU）

```
这个视频没有字幕，用 bili_watch 的 asr 命令在本地转写一遍，
如果判定为"疑似幻觉"就告诉我，不要直接当原文用。
```

- 依赖 Python 3.10~3.14 + faster-whisper（插件面板可一键装）。
- 默认模型 `small`，中文够用；要更准可设 `BILI_ASR_MODEL=medium`（慢 2~3 倍）。
- 有 NVIDIA 卡可开 GPU，约快 2 倍（面板里「转写时用 GPU」）。
- **转写附可信度判定**：`可信` / `疑似幻觉`。后者常见于纯音乐、无人声段、口音极重时。

### B2. 云端 ASR（有网就行）

如果不想装 Python：
- `dsh-bili-eyes` / `dsh-bili-video` 支持硅基流动 SenseVoice（`~/.dsh/asr.json` 填 key）；
- 按分钟计费，中文识别质量不错，但对**动漫台词/强口音**准确率一般。

### B3. 转写质量校验（重要）

ASR 会把专有名词转错（"进程"→"京城"、"快排"→"快牌"）。所以在提示词里加一条：

```
以下是 ASR 转写，可能有错字。请在总结时：
1. 把明显不合理的词按上下文修正，并标注 [已按上下文修正: 原词→新词]
2. 无法确定的保留原样，用 [?] 标记
3. 涉及数字、公式、代码的地方，如果上下文不明确，单独列出来让我核对
```

## 四、场景 C：板书 / PPT / 代码演示

纯口播课不需要看画面，但**推导过程、架构图、代码实操**必须看画面。三级方案：

### C1. 官方截帧（最省，不用 ffmpeg）

```
用 bili_watch 的 peek 看看这条视频，把 5 帧画面和热评给我。
```

`peek` 走 B 站官方截帧接口，不下视频、不依赖 ffmpeg。

### C2. 抽帧 + OCR（把画面变成文字）

```
用 bili_watch 的 frames 命令，--step 30 --ocr，
把整节课的画面文字提取出来，重点关注板书和代码区。
```

- 把"图"变成"字"，DeepSeek 就能读了——这是**当前纯文本模型下唯一可行的视觉路线**。
- 缺点是丢失图形关系（架构图箭头、流程图连线），只能拿到散落的标签。

### C3. 真视觉（需要多模态模型）

```
用 bili_vision 的 inspect 看 {BV号}，重点看 15:00-18:00 的推导过程，
grid-size 1，max-vision 6，我要看清每一步变换。
```

前提：当前对话用的是**支持图片的模型**。DeepSeek 默认不行，
要么换模型，要么用 `run` 配一个独立视觉模型（MiMo 等）。

### C4. 精确定位回看（`dsh-bili-video` 独占）

```
用 video_locate 找一下「老师说这个算法会退化」大概在第几分钟。
```

这个工具的价值在于：**你记得有个点，但忘了在哪**。查一次比拖进度条十分钟强。

## 五、场景 D：系列课管理（`dsh-bili-study`）

### D1. 建目录

装好后侧栏会出现「B 站学习台」。第一步不是收视频，是**让 AI 生成目录**：

```
我要学 {操作系统}，目标是 {能独立实现一个简易调度器}，
时间 {8 周，每周 6 小时}。
请按「科目 → 章 → 主题」给我一个三层目录，
每章标注预计时长和最小学完标准。
```

它会调 `bili_study_save_catalog` 写入目录。

### D2. 收视频

支持三种输入：
- UP 主主页链接（抓全部投稿）
- 收藏夹链接（抓整个收藏夹）
- 单个视频链接

抓回来的都在「未分类」，可以拖拽，也可以：

```
把这批未分类的视频按目录智能分类，先给我看建议，我确认后再写入。
```

> ⚠️ 「智能分类」会先出预览再写入，别直接让它写——标题相似的课经常分错。

### D3. 笔记

- 支持 Markdown 与 KaTeX：行内 `$O(n\log n)$`，块级 `$$...$$`。
- 右侧边看边记，观看进度自动存。
- 笔记可以导出（配合 Obsidian/Notion 用）。

**笔记模板**（可以每次新建主题时贴进去）：

```markdown
## {章节名}

> 视频：https://www.bilibili.com/video/{BV号}?p={P号}&t=0 ｜ 时长 ｜ 首看 {日期}

### 我的目标
（学完这节我要能做什么，一句话）

### 知识点
#### 1. {知识点} `[12:34]`
- 一句话：
- 为什么重要：
- 易错点：

### 公式 / 代码
```
（原样抄，别改写）
```

### 没懂的
- [ ] {问题} → 已问 AI / 待查资料 / 已解决

### 一句话总结
（合上视频，用自己的话写）
```

> 最后那条「合上视频用自己的话写」是整份笔记里唯一真正检验学会没有的动作。
> 前面的都是素材，这条才是产出。

### D4. 概念速查与知识图谱

- 选中一段文字 →「概念速查」→ 直接问 AI，不用离开面板；
- 「知识图谱」把当前科目的主题关系画出来；
- 「AI 前置连线」生成主题之间的先修关系——**用来发现"我是不是跳过了什么"**。

## 六、场景 E：自测与复习

### E1. 出题（提示词）

```
基于这节的笔记，出 5 道题，难度分布 2 易 2 中 1 难：
- 2 道概念辨析（容易混的两个词）
- 2 道应用题（给场景判断该用什么）
- 1 道"如果……会怎样"的反事实题

要求：
- 每题标注考查的知识点和对应时间码
- 先只给题目，我答完再给答案和解析
- 解析里必须指出"错选 X 说明你误以为……"
```

> 「先只给题目」很重要。一次性给答案，你会忍不住看。

### E2. 错题回看

```
第 3 题我答错了，我的答案是 B。
1. 告诉我 B 错在哪（我的推理哪里断了）
2. 这个知识点在原视频第几分钟
3. 用另一种讲法再讲一遍（不要重复老师的讲法）
4. 出一道同类型的变式题
```

### E3. 间隔复习（`dsh-web-studyhub`）

把笔记导进去，它会：
- 生成带出处引用的闪卡；
- 按 **FSRS-6** 算法安排复习时间（比死板的艾宾浩斯更适应你的遗忘曲线）；
- 出测验和开放题。

```
把 {课程名} 这门课的笔记导入 studyhub，按 FSRS-6 排复习计划，
每天不超过 20 张卡。
```

### E4. 周复盘提示词

```
这是我这一周在 B 站学习台的观看记录和笔记列表。
1. 按"投入时间 / 产出笔记 / 自测正确率"给我一个周报
2. 指出哪几节我看了但没记笔记（大概率白看）
3. 哪几个知识点我反复回看（说明没真懂），建议换个讲法重学
4. 下周优先级排序
```

## 七、场景 F：找课

```
用 bili_search 搜「{分布式系统}」，按收藏排序，只看 20 分钟以上的，
给我 8 个候选，每个列出：UP 主、时长、播放、收藏、是不是系列课、一句话判断值不值得看。
```

筛选经验（给 AI 的判断标准，也给你自己）：

| 信号 | 说明 |
|---|---|
| 收藏/播放比 > 5% | 说明是"值得反复看"的课，不是娱乐视频 |
| 有系列/合集 | 成体系，比单集靠谱 |
| 时长 30~90 分钟 | 太短讲不透，太长注意力撑不住 |
| UP 主是机构/教师认证 | 质量下限有保证，但可能照本宣科 |
| 评论区有"求课件/求配套代码" | 说明内容密度高 |

## 八、成本控制：别让一个视频烧掉半天额度

### 8.1 算一笔账

| 内容 | 体量 | 约合 token |
|---|---|---|
| 1 小时口播字幕 | 1.2~1.8 万字中文 | 8k~13k |
| 3 小时系列课 | 4~5 万字 | 30k~40k |
| 一次 `sheet` 九宫格图 | 1 张图 | 1k~4k（且 DeepSeek 用不了） |

### 8.2 三条硬规则

1. **一次只喂一节**。别把整个课程合集丢进去，上下文会稀释，模型会开始胡说。
2. **用落盘 + 分段读**。`dsh-bili-watch` 超过 800 字会自动落盘只回摘要——**这是特性不是 bug**，让模型 `read` 分段读，比一次塞满更准。
3. **图片仅在你真要问"画面里写了什么"时才开**。DeepSeek 纯文本，图白花。

### 8.3 省钱提示词

```
接下来的任务请遵守：
- 不要复述字幕原文，只提炼
- 每个知识点不超过 3 行
- 如果某段是纯复习/纯过渡，直接说"跳过"并给时间码
- 最后给一个"如果时间有限，只看这三段"的清单
```

## 九、完整案例走查：30 分钟一节「进程调度」

| 步 | 你说什么 | 发生什么 | 耗时 |
|---|---|---|---|
| 1 | 「用 bili_watch 把 BV1xx 的字幕导成 md」 | 拿到 40 段带时间码文本，落盘 | 20s |
| 2 | 「按自然段落切分并做分段精讲」（贴模板 A2） | 输出 4 段，每段含结论/前置/锚点 | 60s |
| 3 | 「第 12:30 那个例子没看懂，用抢笔比喻讲」 | 追问，得到通俗解释 | 30s |
| 4 | 「把上面的内容整理成笔记模板，存进学习台」 | `bili_study_*` 写入，带公式 | 20s |
| 5 | 「出 5 道题，先只给题目」 | 5 题 + 知识点/时间码标注 | 30s |
| 6 | （自己答题，答错第 3 题）「第 3 题我选 B」 | 错因分析 + 变式题 | 30s |
| 7 | 「把错题和对应时间码记到笔记的『没懂的』」 | 更新笔记 | 10s |
| 8 | （一周后）「按 studyhub 的复习计划过一遍」 | 闪卡 12 张 | 8min |

**总交互约 3 分钟 + 你自己的答题和观看时间。** 这就是"辅助"的正确比例。

## 十、常见问题

**Q：AI 总结得很空泛，全是"本节介绍了……"怎么办？**
A：两个原因——① 一次喂太长；② 提示词没约束。用 A2 模板，强制它输出「关键结论」「没讲清的」「回看锚点」，空泛的话它写不出来。

**Q：字幕拿不到？**
A：先确认登录态（`bili_watch login` 扫码）；还不行就是视频真没字幕，走 ASR。

**Q：模型说"我无法观看视频"？**
A：它没调用工具。明确说「用 bili_watch 工具」，或检查插件是否挂载（新会话里问「你有哪些 bilibili 相关工具」）。

**Q：笔记记了不看？**
A：那是流程问题不是工具问题。把复习交给 FSRS（studyhub），别靠自律。

**Q：能不能让它自动看我所有的课？**
A：技术上能（`dsh-bili-scroll` 那类），但**不建议**——自动化的总结没有人脑的"卡住感"，你会得到一堆看过就忘的完美笔记。学习恰恰需要那个卡住的过程。
